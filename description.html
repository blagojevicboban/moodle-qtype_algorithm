Algorithm Question Type

A quiz question in which the student draws an algorithm as a flowchart and can run it before submitting.

Features

  • Draw the algorithm with the same editor as in TinyMCE, with Run / Step, variable watch and generated code.
  • Runnable review: the teacher can run and step through the submitted diagram while grading.
  • Manual grading with autosave and an empty-answer check.
  • Analyse an algorithm: put an interactive diagram in the question text (needs filter_algorithm).

What's new in 0.2.0

  • Supports Moodle 4.5 LTS and 5.0 - 5.3 (tested on 4.5 and 5.3).
  • Serbian Cyrillic language files; the editor picks Latin or Cyrillic from the Moodle language.
  • Moodle coding standard (phpcs, ESLint, stylelint) and GitHub Actions with moodle-plugin-ci.

Requirements

  • Moodle 4.5 LTS to 5.3 (PHP as required by your Moodle version).
  • The tiny_algorithm plugin; filter_algorithm is optional (interactive diagrams in question text).

Privacy

The student's answer is stored by the Moodle question engine like any other answer; the diagram runs in the browser and nothing is sent to external services. The plugin implements the Moodle Privacy API.
